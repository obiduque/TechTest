# TechTest
Project that manage tasks and users
1.Como primer paso se deben ejecutar los comando de base datos que se encuentran en la carpeta BD. Ya estan numerados y deben ser ejecutados en orden ascendente (desde el 1 hasta el 2)
2.En la carpeta Back, se encuentra la lógica referente al procesamiento de datos. Es importante setear los datos de la cadena de conexion que se encuentra definida en el archivo launchsettings.json dentro de la carpeta Properties
3.Si se desea desplegar dicho proyecto en un servidor con su respectivo dominio, se debe cambiar en la carpeta Front el archivo enviroment por la url correspondiente antes de construir el proyecto para de ese modo garantizar la comunicacion en el servidor
